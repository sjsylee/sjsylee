# Hello there! 👋
I'm a developer who loves turning complex ideas into polished, real-world products.

I build user-centered solutions with a focus on **UI/UX**, **practical problem solving**, and **end-to-end implementation** — from messy first idea to shipped product.  
Across the stack — from polished interfaces to backend logic, desktop tools to the automation that ties everything together. **Wherever the product needs me.**

---

## <img src="https://play.pokemonshowdown.com/sprites/gen5ani/porygon2.gif" width="28" /> My Development Workflow with AI

I build hands-on across the stack — writing code, shaping flows, refining UX, and digging into the practical engineering problems behind each feature. I lean into AI to move fast, but I stay close to the decisions that matter.

My approach: get clear on the problem before coding, work with tight feedback loops (types, tests, debugging), and care about how the system is shaped — not just whether it runs. AI accelerates my iteration; I drive the direction.

### How I work with AI Agents

| Area | What I Lead | How AI Helps |
|---|---|---|
| 🧩 Product Thinking | Requirements, priorities, edge cases | Surfaces alternatives and uncovers blind spots |
| 🎨 UI/UX Design | Flows, interaction patterns, design system | Iterates on components and visual variations |
| 💻 Development | Architecture, module boundaries, code review | Drafts implementation, refactors, boilerplate |
| 🧪 QA & Testing | Test strategy and coverage decisions | Generates cases, supports red-green-refactor loops |
| 📦 Automation | Workflow design and integrations | Handles scripting and repetitive setup |
| 📝 Documentation | Technical intent and decision records | Drafts and polishes written artifacts |

> I use AI as a sharper tool — not a shortcut around the engineering. The goal is to build faster *and* better, without skipping the parts that make software actually good.
